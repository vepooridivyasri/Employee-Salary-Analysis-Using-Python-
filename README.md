# Employee Salary Analysis using Python

## Project Overview
This project analyzes employee salary data using Python.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Features
- Load employee data from a CSV file
- Calculate average salary
- Find highest and lowest salary
- Count employees by department
- Visualize data using bar charts

## Project Structure
- employee_salary_analysis.py
- employee_salary.csv
- images/

## Output
The project generates:
- Department-wise Employee Count chart
- Employee Salary chart
